# 구현 범위와 검증 경계

## 실제 구현

- Pleos SDK 버전은 Vehicle 2.3.2, FusedLocation 1.1.3, TTS/STT 3.3.1, NaviHelper 3.0.5를 유지한다.
- 공조는 캐빈 전원(`0x75`) → 운전석 온도(`0x1`) → 운전석 열선 순으로 적용한다. 세 단계 모두 성공해야 완료로 알린다.
- 부분 실패 또는 15초 응답 시간 초과 시 전체 캐빈 공조와 열선을 모두 끈다. 종료 실패/무응답은 30초 후 재시도한다. 종료 뒤 늦게 도착한 성공 응답도 다시 종료한다.
- 미탑승 안전 타이머는 전원 요청 전에 등록한다. 10분 동안 차속 5km/h 초과가 감지되지 않으면 공조와 열선 종료를 요청한다. 좌석 점유 센서에 의한 탑승 판정은 구현하지 않았다.
- Activity 종료 시 활성 프리컨디셔닝의 종료를 요청한 뒤 최대 5초 후 연결을 해제한다. 앱 프로세스 강제 종료 후에도 동작하는 원격 예약 서비스는 구현하지 않았다. 실제 차량의 독립적인 안전 종료 기능을 대체하지 않는다.
- AAOS 제한 상태가 미확인이거나 제한 중이면 상세 대시보드, 진단 로그, 시연 버튼과 터치 퀵패널을 숨긴다. 음악 앱/브라우저 진입도 거절한다. 제한이 시작되면 진행 중 시연을 취소한다.
- 취소 명령을 우선 해석하고, 여행/음악/시연 시작을 통근 시작과 구별한다. “더워”는 온도를 내리고 “추워”는 올린다. 단독 “네”는 현재 대기 중 질문만 수락한다.
- 수동 온도는 16~30℃ 범위에서 실제 SDK로 적용하고 성공한 값만 확정·학습한다. GPS 갱신은 해당 세션의 수동 온도를 덮어쓰지 않는다.
- 일반 목적지는 통근으로 강제 분류하지 않는다. 목적지가 있으면 암시적 추론보다 우선한다. 목적지 분류는 키워드 기반이므로 실제 사용자 저장 장소와의 정밀 매칭은 후속 과제다.
- 내비 미설정 시 평일 출퇴근 시간, 연속 GPS의 목적지 접근 방향, 출발지 반경 또는 학습된 출발 시간대를 결합한다. 출발지 기본 좌표는 시연용 양재 본사/강남권이며 개인 장소 설정 화면은 미구현이다.
- 목적지별 제안은 세션당 한 번 발화하며 수락·거절한 제안을 GPS 갱신마다 다시 표시하지 않는다. 학습 완료도 내비 우선순위와 사용자 수락을 생략하지 않는다.
- 최근 최대 200개 통근 이력과 EMA 온도 상태를 로컬 저장한다. 온도 버튼 조작은 별도 통근 횟수로 계산하지 않는다. 시간 평균은 HHmm 정수가 아닌 분 단위로 계산한다.
- 날씨 조회 실패 시 실제 이전 관측값 또는 미확인 상태를 표시한다. 모의 14.5℃를 캐시로 표시하지 않는다. OpenAI 실패 시 로컬 브리핑을 사용한다.

## 시연 및 미구현 기능

- 엔진 시동 ON/OFF API는 호출하지 않는다. 공조·열선 제어를 시동 제어 성공으로 안내하지 않는다.
- 캘린더·메일·뉴스·여행 POI는 고정 시연 데이터다. 실제 Google/Outlook OAuth 연결이나 실시간 뉴스 수집은 구현하지 않았다.
- EQ는 날씨·계절·통근·차속별 **추천값**이다. 외부 YouTube Music 오디오 세션에 Equalizer를 적용하지 않는다. 차속 저역 보정은 제품 튜닝 휴리스틱이며 검증된 논문 수치로 주장하지 않는다.
- 음악 앱/웹 화면 실행 성공은 실제 음원 재생 확인을 뜻하지 않는다. 실행할 앱이 없으면 실패를 반환한다.
- 5단계 투어의 85km/h는 추천값을 보여주는 모의 입력이다. 실제 차속이나 운전자 감지 상태를 변경하지 않는다. 투어는 정차 확인 후에만 가능하다.
- 현재 폴더는 기능별 계층 분리 상태이며 완전한 Clean Architecture 의존성 역전은 아니다. 일부 domain 매니저는 Android/SDK/data 모델을 참조한다. 이번 수정에서는 SDK 어댑터 전체를 이동하는 대규모 리팩터링을 수행하지 않았다.

## 검증

```sh
./scripts/build-android.sh testDebugUnitTest
./scripts/build-android.sh :app:assembleDebug -PexcludeLocalSecrets=true
```

`artifacts/Pleos_CommuteCare.apk`에는 로컬 `.env`와 환경변수의 API 키를 포함하지 않는다. 개인 네트워크 연동 개발 빌드는 기존 `.env` 주입을 사용할 수 있으나 해당 APK를 Git에 추가하지 않는다.

단위 테스트는 비동기 제어 실패/시간 초과/중복·지연 응답, 음성 분기, 통근 오탐, 학습 복원과 차속 추천 보정을 검증한다. 실차 SDK 장치 상태, AAOS 제한 전환 UI, 음악 앱 실제 재생, 프로세스 종료 상황은 별도의 차량/에뮬레이터 검증이 필요하다.
